# ScrollRecorder

Aplikasi rekam dan putar ulang gerakan scroll otomatis di layar HP.

## Fitur
- Rekam gerakan scroll (ke atas/bawah)
- Putar ulang gerakan yang direkam secara otomatis
- Kontrol play / stop
- Data scroll tersimpan di perangkat

## Cara Pakai
1. Tekan tombol "Rekam", lalu scroll halaman ke atas/bawah
2. Tekan "Stop Rekam" untuk menghentikan
3. Tekan "Putar" untuk memutar ulang gerakan yang direkam
4. Tekan "Stop Putar" untuk menghentikan pemutaran

## Build
Gunakan GitHub Actions workflow di `.github/workflows/build_apk.yml`.
